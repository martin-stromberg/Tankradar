# Tankbuch

Im Bereich **Tankbuch** verwalten Sie Ihre Fahrzeuge: Name, Kraftstoffart, Start-Kilometerstand und optional den Startverbrauch. Sie können beliebig viele Fahrzeuge anlegen, bearbeiten und löschen. Alles wird nur auf diesem Gerät gespeichert und ist offline nutzbar. Das Erfassen von Tank- und Ladevorgängen folgt in einer späteren Version.
