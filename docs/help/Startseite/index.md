# Startseite

Die Startseite (Bereich **Favoriten**) zeigt alle Favoritengruppen mit ihren Tankstellen, den aktuellen Preisen der gewählten Spritsorten und auf Wunsch den Bereich **In der Nähe**. Beim Öffnen und auf Wunsch werden die Preise aktualisiert; ohne Verbindung erscheinen die zuletzt bekannten Preise mit Altersangabe.
