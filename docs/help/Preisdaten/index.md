# Kraftstoffpreise und Preis-Cache

Tankatlas bezieht aktuelle Kraftstoffpreise und Tankstellendaten über die Tankerkönig-API (offizielle Daten der Markttransparenzstelle für Kraftstoffe, MTS-K). Jeder abgerufene Preis wird mit Zeitstempel lokal gespeichert, sodass die App auch ohne Verbindung die zuletzt bekannten Preise samt Alter anzeigen kann. Die Quellenangabe „Daten: Tankerkönig / MTS-K“ ist im Bereich **Optionen** sichtbar.
