# Tankstellen-Detailansicht

Tippen Sie in der Ergebnisliste der [Umkreissuche](../Suche/index.md) auf eine Tankstelle (Karte oder Schaltfläche **Details**), öffnet sich die Detailansicht mit Name, Adresse, Entfernung, den Preisen Ihrer aktivierten Spritsorten samt Alter, Hinweisen und Öffnungszeiten.
