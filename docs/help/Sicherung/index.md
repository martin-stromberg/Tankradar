# Sicherung

In den **Optionen** erstellen Sie auf Wunsch eine Sicherung Ihrer Daten, sehen alle vorhandenen Sicherungen mit Datum und Größe, stellen eine Sicherung wieder her, löschen sie, geben sie über „Teilen“ weiter oder spielen eine Sicherungsdatei von außen ein. Alles geschieht nur auf Ihre Veranlassung und lokal auf dem Gerät; Tankatlas überträgt nichts selbst. Die Wiederherstellung ersetzt die aktuellen Daten vollständig und ist atomar: Bei einem Fehler bleiben Ihre Daten unverändert.
