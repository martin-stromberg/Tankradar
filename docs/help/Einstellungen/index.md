# Einstellungen (Optionen)

Im Bereich **Optionen** legen Sie fest, welche Spritsorten Sie interessieren, wie Tankatlas Ihren Standort verwendet, ob die Startseite den Bereich „In der Nähe“ zeigt und wie Suchergebnisse standardmäßig angezeigt werden. Unten finden Sie die Karte **Sicherung** (siehe [Sicherung](../Sicherung/index.md)). Jede Änderung wird sofort auf dem Gerät gespeichert und bleibt nach einem Neustart der App erhalten. Beim ersten Start fragt eine Einrichtung einmalig nach den Spritsorten; sie schreibt dieselbe Einstellung.
