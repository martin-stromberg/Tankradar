# Einstellungen (Optionen)

Im Bereich **Optionen** legen Sie fest, welche Spritsorten Sie interessieren, wie Tankatlas Ihren Standort verwendet und wie Suchergebnisse standardmäßig angezeigt werden. Jede Änderung wird sofort auf dem Gerät gespeichert und bleibt nach einem Neustart der App erhalten.
