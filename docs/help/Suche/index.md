# Umkreissuche

Im Bereich **Karte** suchen Sie Tankstellen im Umkreis Ihres aktuellen Standorts oder rund um eine eingegebene Adresse, einen Ort oder eine Postleitzahl (1 bis 25 km, voreingestellt 5 km) sowie entlang einer Route von einem Start zu einem Ziel. Beim ersten Öffnen in einer Sitzung sucht Tankatlas automatisch im Umkreis von 5 km um Ihren Standort, sofern die Standortnutzung eingeschaltet ist; danach bleibt das Ergebnis beim Wechsel zwischen den Bereichen erhalten. Die Karte (OpenStreetMap) füllt den Bereich aus; die Treffer zeigt sie als farbige Preismarkierungen, die Trefferliste mit Entfernung, Preisen der von Ihnen gewählten Spritsorten und dem Alter der Preise liegt als Panel am unteren Rand. Die Suche öffnen Sie über die Schaltfläche **Suche** auf der Karte; Treffer lassen sich nach Spritsorte filtern und sortieren.
