# Umkreissuche

Im Bereich **Karte** suchen Sie Tankstellen im Umkreis Ihres aktuellen Standorts (1 bis 25 km, voreingestellt 5 km). Die Treffer erscheinen als Liste mit Entfernung, Preisen der von Ihnen gewählten Spritsorten und dem Alter der Preise; sie lassen sich nach Spritsorte filtern und sortieren.
