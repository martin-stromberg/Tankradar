# Navigation und Design-System

Tankatlas präsentiert beim Start eine klare Benutzeroberfläche mit vier Hauptbereichen, zwischen denen Sie einfach navigieren können. Das Design-System sorgt für eine konsistente und angenehme Bedienung in Hell- und Dunkelmodus.
