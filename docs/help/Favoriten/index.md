# Favoritengruppen

Tankstellen lassen sich in der [Detailansicht](../Tankstellendetails/index.md) selbst benannten Gruppen zuordnen (z. B. „Arbeitsweg“, „Heimat“, „Urlaub“). Im Bereich **Favoriten** sehen Sie die Gruppen auf der [Startseite](../Startseite/index.md), verwalten sie und pflegen Notiz und Priorität je Tankstelle. Alles wird lokal gespeichert und ist offline verfügbar.
