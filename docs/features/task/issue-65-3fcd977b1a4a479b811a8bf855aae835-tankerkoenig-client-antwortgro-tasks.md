## Prüfergebnis Handler-Lifetime (Issue #65, Prüfaufgabe)

Alle vier externen Dienste (Tankerkönig, Nominatim, OpenRouteService, Kartenkacheln/`HttpTileSource`) nutzen manuell erzeugte Singleton-`HttpClient`s mit `HttpClientHandler`. Ergebnis der Prüfung:

- **`SocketsHttpHandler.PooledConnectionLifetime`:** fachlich sinnvoll (Singleton-`HttpClient`s übernehmen DNS-Änderungen sonst nie). Empfehlung: einheitliches Follow-up für alle vier Dienste, nicht Teil dieses Changes.
- **`IHttpClientFactory`:** wird nicht empfohlen — erfordert das bislang nicht referenzierte Paket `Microsoft.Extensions.Http` und bringt für reine Singleton-Clients ohne Delegating-Handler-Pipeline keinen Mehrwert.
